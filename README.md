# Planet.com — simulador académico de atención comercial

Demostración web gratuita **sin API ni inteligencia artificial generativa**. Respuestas por reglas programadas en JavaScript; sin conexión con WhatsApp, Google Sheets ni inventarios reales.

Los cinco registros son ficticios: Notebook Demo A ($900.000), Notebook Demo B ($720.000), Mochila Demo Urbana ($65.000), Mochila Demo Ejecutiva ($82.000), Servicio Técnico Demo (sin precio). Los importes son **precios de prueba, no reales**.

## Publicación en GitHub Pages
Abrí Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save. Una vez completada la publicación, abrí https://fernandamagri.github.io/planet-digital-web-ia1/.

## Uso académico
Esta demo complementa las diez pruebas de IA generativa realizadas separadamente en ChatGPT. No deben confundirse sus resultados: aquí se prueban reglas y patrones programados, no razonamiento ni generación autónoma.

## Privacidad
No ingreses información personal: la demo no necesita nombres, teléfonos, ni información sensible.
